# 使用说明（操作手册）

适用：RK3588 小车（Toybrick + 麦轮底盘 + LD14P 雷达）——**建图 / 遥控**的日常操作
更新：2026-09-20
（开发细节见《04_SLAM建图实验方案.md》《07_ROS2常用命令.md》《08_自主导航实验方案.md》）

> **打印版速查卡**：同目录 `速查卡.pdf`（A4 单页，可直接打印贴车上 / 带现场）；
> 源文件 `速查卡.html`（浏览器打开按 Ctrl-P 也能打印，改动后重出 PDF 见文末说明）。
> 重出 PDF 的命令：`soffice --headless --infilter="HTML (StarWriter)" --convert-to pdf --outdir . 速查卡.html`

> **最短路径**（会这三条就够用）：
>
> ```bash
> robot        # ① 一键启动（底盘 + 雷达 + SLAM + 手机遥控），约 10 秒
> #  ② 手机连同一个 WiFi → 浏览器打开终端打印的地址 → 摇杆遥控建图
> #  ③ 建完点手机右上角「保存地图」→ 存到 ~/RobotCode/04_map/map_<时间戳>.*
> #  停止：在启动终端按 Ctrl-C（或另开终端 robotstop）
> ```

## 1. 开机前检查（30 秒）

| 检查 | 怎么查 | 正常现象 |
|---|---|---|
| 底盘 USB | `ls -l /dev/CAR_BASE` | 指向 `ttyCH341USB0` |
| 雷达 USB | `ls -l /dev/LD14P` | 指向 `ttyACM0` |
| 网络 | `myip` | 有 `192.168.x.x`（手机要连**同一个** WiFi） |
| 电量 | 驱动板指示灯 / 电池 | 建图耗电快，建议先充满（长时间实验注意散热） |

> 串口同一时刻只能被一个程序占用。若旧程序还占着，`robotcheck` 会直接报出来。

## 2. 一键启动（约 10 秒）

```bash
robot
```

看到下面这样的输出就算好了（4 个 ✓ + 手机地址）：

```
✓ 底盘 已启动（pid ...）      ✓ 雷达 已启动      ✓ SLAM 已启动      ✓ 手机遥控 已启动
 手机浏览器打开： http://192.168.31.73:8080/
 手机页面：虚拟摇杆遥控 + 实时地图 + 「保存地图」按钮
```

| 命令 | 作用 |
|---|---|
| `robot` | 一键启动全套（先做预检查；若已有实例在跑会拒绝启动并提示） |
| `robotcheck` | **只检查**：设备是否在位、是否已有实例在跑（不动任何进程） |
| `robotstop` | 停止全套：先发零速度 → 手机 → SLAM → 雷达 → 底盘；**在启动终端按 Ctrl-C 等价** |

- 每轮启动的日志：`~/RobotCode/logs/run_<月日_时分>/`（`chassis.log` / `lidar.log` / `slam.log` / `phone.log`）
- 运行中某个节点掉线，脚本会打印它的日志尾部提醒

## 3. 手机端操作

1. 手机连**与小车的同一个 WiFi**
2. 浏览器打开启动时打印的地址：`http://<小车IP>:8080/`（IP 也可用 `myip` 查）

页面分三块：

| 区域 | 内容 |
|---|---|
| 地图（上） | 实时 SLAM 地图：**白=空闲、黑=障碍、灰=未知**；红色三角=车的位置与朝向；左上角是连接状态 / 位姿 / 速度 |
| 右上角按钮 | **保存地图**（见 §5） |
| 摇杆（下） | 虚拟摇杆（上=前进、左右=转向，**松手即停**）、大号「停 止」、前进/转向上限滑条 |

- 速度建议 ≤ **0.15 m/s**（滑条默认值）；雷达只有 6 Hz，走快了地图会糊
- 桌面浏览器也能用：方向键（↑↓ 前后、←→ 转向）、空格 停
- **三层停车保护**：松手即停 → 板上看门狗 0.6 s 自动停 → 底盘看门狗 0.5 s 自动停

## 4. 建图流程（推荐）

1. 车放在起点、朝向场内，先**原地转一圈**让雷达扫全四周
   （手机：摇杆只推左右慢慢转；或终端 `drive spin` 自动转 360°）
2. 慢速走一圈：**沿墙走**、尽量**绕回起点**（回环让地图闭合更准）
   - 速度 ≤0.15 m/s；**不要横移**（麦轮横移时里程计不可信）；避开玻璃 / 镜面 / 纯黑物体
   - 随时看手机地图：**灰色是还没扫到的区域**，把目标区域都走成白/黑才算建全
3. 回到起点附近 → 停车
4. 点右上角「保存地图」

> 不想手动走也可以让车自己走（终端执行，详见 `drive -h`）：
> `drive spin` 原地一圈 ｜ `drive square -d 1.5` 方形闭环 ｜
> `drive grid -L 2 -W 0.8 -n 3` 弓字形扫面 ｜ `drive -p "f2;t90;f1;t90;f2;t90;f1;t90"` 自定义回环路线

## 5. 保存地图

**手机点「保存地图」**（推荐）：会**先自动停车**，然后一次存出一套四件，文件名自动带时间戳：

```
~/RobotCode/04_map/
├── map_20260920_1245.pgm        栅格图（看图用：白=空闲 黑=障碍 灰=未知）
├── map_20260920_1245.yaml       配套参数（分辨率 / 原点，导航可直接用）
├── map_20260920_1245.posegraph  建图序列（以后续建 / 定位模式加载）
└── map_20260920_1245.data       序列配套数据
```

- 终端等价命令：`savemap`（自定义前缀：`python3 ~/RobotCode/01_Project/03_SLAM/save_map.py -n 房间A`）
- **时间戳命名 ⇒ 每次存档都保留**，不会覆盖上一次
- 在电脑上看图：把 `.pgm` 用图片查看器打开即可；实时看用 `mapv`

## 6. 常用命令速查

| 命令 | 作用 |
|---|---|
| `robot` / `robotstop` / `robotcheck` | 一键启动 / 停止 / 预检查 |
| `phone` | 只启动手机遥控网页（不带底盘/雷达/SLAM，调试用） |
| `drive ...` | 自动行驶建图（`spin` / `square` / `grid` / `home` / 自定义路线） |
| `mapv` | 实时地图（OpenCV，触摸屏或终端） |
| `scanview` | 雷达点云（OpenCV） |
| `savemap` | 保存地图（时间戳四件套 → `04_map/`） |
| `odomhz` / `scanhz` | 看底盘里程计 / 雷达频率（判断"活着没"最快） |
| `tfc` | 生成 TF 树图（应见 `map→odom→base_link→base_laser`） |
| `myip` / `whocar` / `wholidar` | 查 IP / 查底盘串口占用 / 查雷达串口占用 |
| `car` / `lidar` / `slam` | 手动分三个终端启动（不用一键脚本时） |

> 新开的终端第一次使用先执行 `sr`（source ROS 环境）；以上都是 `~/.bash_aliases` 里的别名，输入 `alias` 可看全部。

## 7. 出问题怎么办

| 现象 | 先查 | 处理 |
|---|---|---|
| 手机打不开网页 | 同一 WiFi？地址对不对（`myip`） | `robotcheck` 看手机遥控是否在跑；重开浏览器 |
| 车不动 | `odomhz` 有没有频率；`ros2 topic info /cmd_vel` 的 Subscription 是否为 1 | 串口被占（`whocar`）→ 关掉占用程序；或重启底盘节点 |
| 底盘"串口假死" | `/odom` 突然没数据、发指令不走 | **重启底盘节点**（读写同时失灵先怀疑物理层/USB 重枚举） |
| 地图没变化 | `ros2 topic hz /map` | 没数据 → 重启 SLAM；有数据但只 0.2 Hz → 查 `map_update_interval`（应为 1.0） |
| 雷达没数据 | `scanhz`；`wholidar` | USB 重插；确认没有直连串口的工具在抢（`lidarview` 与雷达 launch 二选一） |
| 保存地图失败 | SLAM 是否在跑 | 保存依赖 slam_toolbox 的服务与 `/map`；看 `phone.log` 里的提示 |
| 摇杆松手车还在走 | —— | 立即点「停 止」，或在终端 `robotstop` |
| 整个乱了 | —— | `robotstop` → 等 2 秒 → `robot` |

## 8. 安全与注意事项

1. **没有避障功能**：车只按指令走。清空场地、留人看护，手边随时能按「停 止」或断总电
2. 速度 ≤0.2 m/s；**不要横移**（里程计不可信）；贴墙太近有盲区
3. 不要同时开两套（`robot` 会拦下并发启动）
4. 手机遥控网页**只监听局域网、无鉴权**：只在小车自己的网络里用，用完 Ctrl-C 关掉
5. 长时间建图注意电量与散热（SLAM 持续吃 CPU）；屏幕可拔掉省电（地图看手机即可）
6. 地图是重要产物：每次建完都点一次「保存地图」（时间戳不会覆盖），并定期把 `04_map/` 拷到电脑备份
