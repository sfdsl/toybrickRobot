# 雷达实验方案（LD14P）

适用设备：RK3588（Toybrick）+ LD14P 2D 激光雷达（乐动 LDROBOT，USB-CH9102）
适用驱动：`ros2_ws/src/ldlidar`（官方 SDK v2.2.1）
制定日期：2026-09-20
前置条件：

- udev 别名已部署：`/dev/LD14P`（雷达）、`/dev/CAR_BASE`（底盘），规则 `99-robot.rules`
- 驱动包已构建：`colcon build --packages-select ldlidar`
- 硬件接入与驱动已跑通（2026-09-20 实测 `/scan` @ 6 Hz，见《05_实验记录与结论.md》实验 4）

本方案的目标：按"**硬件 → ROS 数据 → 安装标定 → 与底盘联合**"四层逐步验证，
为步骤 5（SLAM 建图）做好数据层准备。

## 实验 R3：安装位置与朝向标定（约 10 分钟）【已通过】

**目的**：确认"**雷达 0° 方向 = 车头正前方**"，并实测安装高度更新 TF。

**原理**：2D SLAM 的地图方向直接由雷达朝向决定——若雷达 0° 与车头存在固定偏角，
建出的地图与定位都会带系统偏差；安装高度（TF 的 z 值）用于多传感器对齐。

**步骤**：

1. 把车摆正，**车头正对**一面墙 / 纸箱，卷尺量好距离（约 0.6 ~ 1.0 m）
2. 运行 viewer，观察"最近障碍"的距离与方位角：

   ```bash
   cd ~/RobotCode/01_Project/02_CameraLeida
   python3 lidar_viewer.py --headless
   ```

   > 终端输出格式：`组帧 6.0 Hz | 667 点 | 最近 0.66 m @ −96.9°`
   > 角度为右手系、按 **−180° ~ +180°** 显示：正前方 0°、逆时针为正，
   > 车正左 ≈ +90°、车正右 ≈ −90°
   > （2026-09-20 改进：方位角加入 headless 输出；显示范围由 0~360 改为 −180~+180。
   >  注意早期的 0~360 显示：270° ≡ −90°、209° ≡ −151°）

   > **注意"抢镜"问题**：终端报的"最近障碍"是**全场最近**——若车后 / 侧面存在
   > 更近的物体（如墙），会盖过你要测的目标。判断目标方位时要**认准目标的
   > 距离值**（如箱子 0.84 m）对应的角度；或临时把其它近物挪远。
   > 例（2026-09-20 实测）：箱子在车正前 0.84 m（读数 359°，正常），
   > 但车后 0.79 m 有墙，终端一直被墙"抢镜"显示 209°。

3. 把障碍物平移到"车正左方""车正右方"，各读一次方位角
4. 卷尺实测**雷达中心**的高度，与 launch 里 TF 的 `z=0.18` 对比
   - 基准面说明：`base_link` 原点在**地面平面**（2D 里程计约定，TF 的 z=0），
     故 0.18 的含义是"**雷达中心离地 0.18 m**"——从**车轮着地平面**垂直量到雷达中心
   - 不便直接量离地高度时：量"底板平面→雷达中心" + "底板离地高度"，两段相加

**数据记录表**：

| 障碍位置 | viewer 显示方位角 | 预期 |
|---|---|---|
| 车正前方 | **0.3°** | ≈ 0°（±10° 内） ✓ |
| 车正左方 | **86.3 / 91.3 / 80.9°** | ≈ +90° ✓ |
| 车正右方 | **−96.9°**（早期 0~360 显示为 260.5°） | ≈ −90° ✓ |
| 正前方距离 | **0.84 m**（卷尺 0.8 m） | 误差 < 5% ✓ |
| 雷达安装高度 | **0.30 m** | 对比 TF 0.18 → 已更新为 0.30 ✓ |

**判据**：

- 正前方障碍方位角在 **±10°** 内 → 朝向合格；
  否则调整安装角度，或在 TF 的 yaw 中记录偏角补偿
- 高度实测值与 0.18 相差 > 2 cm 时，更新 `ld14p.launch.py` 中
  `static_transform_publisher` 的 z 参数并重新启动

**目的**：完整 TF 树 + "边动边扫"数据流验证（SLAM 的直接前置）。

**步骤**：

1. 开三个终端：

   ```bash

2. 边动边扫：慢速驱动底盘，同时观察数据流（另开终端）：

   ```

3. 观察 `/scan` 频率在运动中是否稳定（保持在 6 Hz 左右、无掉线）：

   ```bash
   ros2 topic hz /scan
   ```

## 注意事项与已知局限

1. **串口互斥**：ROS 驱动 / `lidar_viewer.py` / `camera_lidar_view.py` 同一时刻只能开一个
2. **2D 单线**：只扫一个高度平面——地面杂物、台阶上下方看不到，SLAM 里需注意
3. **6 Hz 低频**：移动速度建议 ≤ 0.3 m/s，过快时点云扭曲（建图会变形）
4. **三角测距特性**：黑色 / 高反光 / 透明物体测距可能异常，强日光直射影响精度
5. **USB 供电**：如遇数据掉线，改用直连板子的 USB 口（避免经过 hub）
6. 相关命令合集见《06_实验步骤相关命令.md》"雷达（LD14P）"章节
