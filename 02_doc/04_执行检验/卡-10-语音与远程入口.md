## 二、意图词表（有限集合，需人工确认）

`stop`（停止/停/停下/快停/别动）· `forward`（前进）· `back`（后退/倒退）· `left`（左转）·
`right`（右转）· `home`（回原点/回家）· `goto_place`（去/到/前往/回 + 地点名）·
`patrol_start`（开始巡逻）· `patrol_stop`（停止巡逻）

- 词表外话语**拒绝且不触发动作**（parse 返回 None，日志记「拒绝（词表外）」）
- `goto_place` **只查 `04_map/robot_map.places.json`**（精确 → 全半角归一 → 子串包含；多候选拒绝并提示说全名）；未命中/换图拒绝，不发目标
- 手动类限速 ≤0.10 m/s、限时默认 1.5s（线性 ≤3s、旋转 ≤5s）自动归零
- `stop` 最高优先、免鉴权、幂等豁免：直通 `patrol.cancel + wp_clear + clear_goal + publish_control('stop')`

## 四、安全红线（卡-04/05 逐条落实）

- [x] 不直发 `/cmd_vel`：一切速度经 `set_cmd → /cmd_vel_manual → control_mux → collision_monitor`
- [x] 不明文上云：mqtt_bridge 默认 8883 TLS，`--no-tls` 仅本地调试且打警告
- [x] 凭证不进代码：MQTT 账号/密码/证书走环境变量或密钥文件；robot_ui token 落盘 `~/.robot_ui_token`（0600）
- [x] 消息三要素：dev / ts / seq；seq 去旧 + req_id 幂等双保险
- [x] 心跳租约只作用于远程租约；本地停止与已获准自主任务不受云端断网影响
- [x] 超长帧/非法 JSON/字段缺失 → 拒绝并回 `ok:false`，不崩溃、不停车
- [x] 遗嘱与重连：`presence` retain + LWT，重连后重订阅并重发 `online`（红队坑对策）
- [x] 串口禁用 `/dev/ttyACM0`（底盘口），start_robot.sh 与 app.py 双重拦截
