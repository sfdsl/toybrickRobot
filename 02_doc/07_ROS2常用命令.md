工作空间：`~/RobotCode/ros2_ws`（`base_driver` 底盘节点 + `ldlidar` 雷达驱动）
更新：2026-09-20

## 1. 总览类（看有什么）

| 命令 | 作用 |
|---|---|
| `ros2 topic list` | 列出所有话题（本项目应有：`/cmd_vel` `/odom` `/scan` `/tf` `/tf_static`） |
| `ros2 node list` | 列出所有节点（`/base_driver`、`/ldlidar_publisher_ld14p` 等） |
| `ros2 topic info /scan` | 话题的发布/订阅者数量、消息类型 |
| `ros2 node info /base_driver` | 某节点的订阅、发布、TF 详情 |
| `ros2 topic type /scan` | 只看某话题的消息类型 |

## 2. 看数据（调试核心）

| 命令 | 作用 |
|---|---|
| `ros2 topic hz /odom` | **看发布频率（判断"活着没"最快的命令）** |
| `ros2 topic echo /odom --no-arr` | 打印消息内容（`--no-arr` 隐藏数组字段，输出更短） |
| `timeout 5 ros2 topic echo /odom --no-arr 2>/dev/null \| head -35` | **读一条快照**（本机 ros2cli 0.9.11 没有 `--once`，用 head 截断） |
| `ros2 topic echo /odom --no-arr \| grep -A3 "position:"` | 连续观察位置变化（边驱动边看） |
| `ros2 topic bw /scan` | 看话题的带宽 |

**`ros2 topic hz` 输出读法**：

```
average rate: 19.990                               ← 平均频率 ≈ 20 Hz（设计值，正常）
        min: 0.044s max: 0.054s std dev: 0.00303s  ← 相邻消息间隔的最小/最大/标准差
        		                                     （44ms = 22.7Hz，54ms = 18.5Hz；波动小 = 稳定）
        window: 21                                 ← 统计窗口内累计消息数（持续递增）
```

## 3. 发指令（控制）

```bash
# 前进 0.15 m/s（-r 10 表示以 10Hz 持续发布；Ctrl+C 停止，0.5s 后看门狗自动停车）
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.15}}"

# 原地左转 / 右转
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist "{angular: {z: 0.5}}"
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist "{angular: {z: -0.5}}"

# 确认底盘节点在监听（Subscription count 应为 1）
ros2 topic info /cmd_vel
```

## 7. 本项目已知坑（实测汇总）

1. `view_frames` 必须写 **`view_frames.py`**（带后缀，否则报 No executable found）
2. 本机 ros2cli 0.9.11 **没有 `--once`** → 用 `timeout + head` 实现"读一次"
3. `--no-arr` 可隐藏数组字段（covariance / ranges），让输出可读
4. **串口互斥**：`/dev/LD14P`（雷达）与 `/dev/CAR_BASE`（底盘）各自同时只能一个程序使用；
   含"同一程序重复启动多个实例"——实测多个进程同读一个串口会**瓜分数据、全都收不到完整帧**
   （表现全是 waiting）。启动前先查占用：`wholidar`（雷达）/ `whocar`（底盘）
5. 所有广播者都停发时，`ros2 topic hz /tf` 会提示 "does not appear to be published yet"（这是提示不是报错）
6. 设备固定别名（udev）：**`/dev/LD14P`**（雷达）、**`/dev/CAR_BASE`**（底盘）
7. 数据异常先怀疑**物理层**（电源/USB 重连），再看 ROS 层——"读写同时失灵"几乎必是串口对端问题

## 8. 一句话诊断流程（小车不动 / 数据异常时）

```text
1. ros2 topic hz /odom        无频率 → 底盘节点假死或底盘掉电 → 重启节点
2. ros2 topic hz /scan        无频率 → 雷达问题（串口被占 / USB 掉线）
3. ros2 topic info /cmd_vel   Subscription count 应为 1（底盘节点在听）
4. ros2 run tf2_tools view_frames.py
                              完整链应为 odom → base_link → base_laser
```

## 9. 手机遥控（网页版，无需装 App）

小车自己当服务器，手机连同一 WiFi 用浏览器打开即可——遥控 + 实时看地图。

```bash
phone                        # 默认端口 8080，地图视野 8 米（终端会打印手机要打开的地址）
phone -p 9000 -r 12          # 换端口 / 换视野
myip                         # 查小车 IP → 手机打开 http://<该IP>:8080/
```

| 项 | 说明 |
|---|---|
| 操作 | 虚拟摇杆：上=前进、左右=转向（松手即停）；大号"停止"键；速度上限滑条 |
| 桌面调试 | 同一页面可用方向键（↑↓ 前后、←→ 转向、空格 停） |
| 画面 | 实时 SLAM 地图（MJPEG 推流，8 fps）+ 车辆位置/速度 HUD（左上角「≡」可折叠，不挡地图） |
| 地图手势 | **点一下**=设目标 ｜ **拖动**=平移 ｜ **捏合**=缩放（1~20 m，**服务端重渲染**，放大不糊） ｜ **双击**=复位（回车上） ｜ 桌面用右下角 ＋ － ⟳ |
| 点选目标 | 地图上**点一下** = 设导航目标 → 发 `/goal_pose`；红圈+十字标注 |
| 连续导航 | `nav --listen` 是**连续模式**（到点后继续等下一个；行驶中再点立刻改道）；或一条命令 `robotnav --nav` 起全套 |
| 停车/取消 | 右上角「清除目标·停车」= 清除目标**并让导航就地停车**（比「停 止」可靠：只按停止的话导航下一拍会继续发指令） |
| 接口 | `/cmd?vx=&wz=`（发速度）、`/stop`、`/state`（JSON 状态，含 `goal`/`view`）、`/stream.mjpg`、`/goal?u=&v=`（画面像素）或 `/goal?x=&y=`（世界坐标）、`/goal/clear`、`/view?range=&dx=&dy=`、`/view?reset=1` |
| 停车保护 | 三层：松手即发零速 → 0.6 s 无指令自动停 → 底盘看门狗 0.5 s 自动停 |
| 本机自测 | 板子上**没有 curl**，用 `wget -qO- http://127.0.0.1:8080/state` |
| 注意 | 只监听局域网、无鉴权，实验结束记得 Ctrl-C 关闭；不适用于公网 |

## 10. 一键启动 / 停止 · 保存地图

```bash
robot          # 一键启动全套：底盘 + 雷达 + SLAM + 手机遥控（启动前自动预检查）
robotcheck     # 只做预检查（设备是否在位、是否已有实例在跑）——不动任何进程
robotstop      # 停止全套（先发零速度，再按序退出）；等价于在启动终端 Ctrl-C
savemap        # 保存地图 → ~/RobotCode/04_map/，文件名自动带时间戳
```

| 项 | 说明 |
|---|---|
| 一键启动 | `robot`（建图模式）｜ `robotnav`（定位模式，导航用）｜ **`robotnav --nav`（定位 + 导航监听：手机点地图即出发，可连续点）** |
| 实现方式 | **ROS 2 launch**：`ros2 launch robot_bringup bringup.launch.py [mode:=localization bag:=true]`（`--show-args` 看参数） |
| 脚本定位 | `~/RobotCode/start_robot.sh` 只做「预检查」与「急停」，启动/停止由 launch 统一管理 |
| 手机入口 | 启动后终端打印 `http://<小车IP>:8080/`：虚拟摇杆 + 实时地图 + 「保存地图」按钮 |
| 保存内容 | `map_<时间戳>.pgm` + `.yaml`（看图/导航）+ `.posegraph` + `.data`（可续建） |
| 地图目录 | **`~/RobotCode/04_map/`**（时间戳命名，每次存档都保留，不会互相覆盖） |
| 日志 | 节点日志：launch 打印的 `~/.ros/log/<时间>/`；rosbag：`~/RobotCode/logs/bags/run_<月日_时分>/` |
