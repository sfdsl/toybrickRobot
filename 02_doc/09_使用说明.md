# 使用说明（操作手册）

适用：RK3588 小车（Toybrick TB-RK3588SD + 麦轮底盘 + LD14P 雷达 + USB 相机）
——**建图 / 遥控 / Nav2 自主导航 / 巡逻 / 视觉检测**的日常操作
更新：2026-09-23（四屏控制台 + 视觉链路 + `--vision` 一键启动）
（开发细节见文末《相关文档》；本篇只讲"怎么用"）

> **最短路径**（会这几条就够用）：
>
> ```bash
> robotnav --nav2            # ① 一键启动：底盘+雷达+SLAM定位+Nav2导航+六屏UI（不跑识别、不开相机）
> robotnav --nav2 --cam      #    同上 + 相机原始画面（仍不识别）
> robotnav --nav2 --vision   #    全开：再加 NPU 的 YOLO11 检测（要看识别画面时用这条）
> #  ② 手机连同一个 WiFi → 浏览器打开终端打印的地址（带 k=token）
> #     「遥控」屏摇杆 ｜ 地图点一下=导航出发 ｜ 「航点」屏巡逻 ｜ 「功能」屏看实时检测画面
> #  ③ 停止：启动终端 Ctrl-C（收底盘/雷达/SLAM/Nav2）→ robotstop（收视觉三件套+清残留）
> ```

---

## 1. 开机前检查（30 秒）

| 检查 | 怎么查 | 正常现象 |
|---|---|---|
| 底盘 USB | `ls -l /dev/CAR_BASE` | 指向 `ttyCH341USB0` |
| 雷达 USB | `ls -l /dev/LD14P` | 指向 `ttyACM0` |
| 相机 | `ls -l /dev/video0` | 存在且任意用户可读写（udev 规则已放开） |
| NPU | `ls /dev/dri/renderD*` | 存在（yolo11 检测用） |
| 网络 | `myip` | 有 `192.168.x.x`（手机连**同一个** WiFi） |
| 电量 | 驱动板指示灯 / 电池 | 导航+视觉同时跑耗电快，建议充满 |

> 串口同一时刻只能被一个程序占用；旧程序占着时 `robotcheck` 会直接报出来。

## 2. 一键启动

```bash
robot                    # 建图模式：底盘+雷达+SLAM(建图)+六屏UI
robotnav                 # 定位模式：同上但 SLAM 加载 04_map/robot_map（自主导航前用）
robotnav --nav           # + 自研导航监听（手机点地图即出发，连续可点）
robotnav --nav2          # + Nav2 全栈（手机点地图 → /goal_pose → Nav2 规划跟踪）
robotnav --nav2 --cam        # + 相机原始画面（仍不跑 YOLO11，省 NPU）
robotnav --nav2 --vision     # + 相机 + YOLO11 检测画面（要识别用这条）
robotnav --nav2 --ekf        # + EKF 融合（轮速+IMU）—— 日常导航推荐这条
robotnav --stop              # 急停：先发零速度，再收掉所有节点（= robotstop）
```

> **七屏网页 UI（遥控/航点/巡逻/探索/编辑/语音/功能）总是启动，不需要任何参数。**
> 三档只是"开到哪一层"的区别：什么都不加（只页面）→ `--cam`（页面 + 相机原始画面）
> → `--vision`（页面 + 相机 + YOLO11 检测）。
> 只想遥控/导航/巡逻时**什么都不加**：相机不占、NPU 完全空闲、CPU 最轻。
>
> ⚠️ **`--ui` 已无作用**（网页总是启动，写不写都一样）；它只保留为兼容参数。
> 旧的 `phone_teleop.py` 单屏 UI（没有探索/编辑屏）已于 2026-10-20 归档到
> `01_Project/bak_phone_teleop_20261020/`，现在任何启动方式拿到的都是六屏 UI。

> **`--ekf`（卡-02）**：开启 `robot_localization` 融合 —— `odom→base_link` 改由 EKF 发布
> （底盘自动 `publish_tf:=false`，不会双发布）。**不加时用原始轮速里程计**，
> 它有约 2% 标度误差和原地打滑，跑几米就能累积几十厘米。
> 可加在任意模式后面，但**日常导航建议固定带上**：`robotnav --nav2 --ekf`。
> 代价：多一个 `ekf_node` 进程 + IMU 驱动（读 `/dev/i2c-6`）。
> 前提：IMU 朝向已标定（`imu_roll=3.14159` 已固化在 `ekf.launch.py`，无需手打）。

| 进程 | 作用 | 默认 | `--cam` | `--vision` | 日志 |
|---|---|:--:|:--:|:--:|---|
| `robot_ui` | **六屏**手机控制台（HTTP 8080，含 `/cam.mjpg`）——**总是启动** | ✓ | ✓ | ✓ | `/tmp/robot_ui.log` |
| `cam_pub` | USB 相机采集 → `/image_raw`（30 FPS） | — | ✓ | ✓ | `/tmp/cam_pub.log` |
| `rknn_infer` | YOLO11 三核 NPU 推理 → `/detections` + 画框 JPEG `/image_det` | — | — | ✓ | `/tmp/rknn_infer.log` |

> `/cam.mjpg` 自动取画面：跑 `rknn_infer` 时是**检测框画面**，只跑 `cam_pub` 时是**原始相机画面**，
> 都没跑则无画面（`src=none`，功能屏会写明"cam_pub 未运行"）。
> 来源可在 `curl -s localhost:8080/state | jq .cam` 里看（`src` = `det` / `raw` / `none`）。
> `--cam` 只是"多开一个相机"，网页 UI 本来就在跑，所以页面上能看到画面。

**停止语义**（重要）：
- 启动终端 **Ctrl-C**：只收 launch 管的（底盘/雷达/SLAM/Nav2）
- **`robotstop`**：全收（含视觉三件套）+ 清 Fast DDS 共享内存残留 + 清 `~/.ros/log`
- 视觉三件套是独立后台进程（`nohup`），Ctrl-C 不会带走它们

> 不想手动走也可以让车自己走建图（`drive -h`）：`drive spin` 原地一圈 ｜
> `drive square -d 1.5` 方形闭环 ｜ `drive grid -L 2 -W 0.8 -n 3` 弓字形扫面

## 3. 手机控制台（七屏 UI）

手机连**与小车同一个 WiFi** → 浏览器打开启动打印的地址：
`http://<小车IP>:8080/?k=<token>`（token 在 `robot_ui` 启动日志里，`cat /tmp/robot_ui.log` 可查；
老版本无 token。IP 用 `myip` 查）

底部七个胶囊切屏：

| 屏 | 路径 | 功能 |
|---|---|---|
| **遥控** | `/` | 摇杆遥控（松手即停）+ 实时地图（白=空闲 黑=障碍 灰=未知）+ 保存地图 + 地图点一下=设导航目标 |
| **航点** | `/nav.html` | 地图点选/拖动添加巡逻点、每点停留秒数、循环开关、「开始巡逻」 |
| **巡逻** | `/patrol.html` | 巡逻进度实时卡（第几点/耗时/每点状态），暂停/恢复/跳过/取消 |
| **探索** | `/explore.html` | 前沿探索建图（续建已有图 / 从零探索），存档不切（见 §5.2） |
| **编辑** | `/edit.html` | 擦假障碍、画虚拟墙、另存新版本不覆盖原图（见 §5.2） |
| **语音** | `/voice.html` | 说话下意图 + TTS 播报 + 全宽红色「停 止」兜底（见 §5.3） |
| **功能** | `/hub.html` | 功能清单 + **实时检测画面**（YOLO11 画框，~10fps） |

**控制权互斥**（ModeMgr，防止两个页面抢车）：
- 摇杆 TELEOP 3 秒无指令自动让出；点地图导航 NAV 5 分钟无操作自动让出
- 「开始巡逻」PATROL 会**接管** NAV/摇杆（用户明确动作优先）
- 被拒时页面会提示"被 XX 占用"——等它自动让出，或点遥控屏「停止」/地图「清空」立即释放
- 巡逻保护：单点失败自动跳过继续；总时长超 30 分钟自动终止

**速度与安全**：摇杆默认上限 0.15 m/s（Nav2 内部上限 0.20 m/s）；
**三层停车保护**：松手即停 → 板上看门狗 0.6 s → 底盘看门狗 0.5 s。
桌面浏览器也能遥控：方向键前后转向、空格停。

## 4. 建图流程（推荐）

1. 车放起点、朝向场内，先**原地转一圈**扫全四周（摇杆慢推左右）
2. 慢速走一圈：**沿墙走**、尽量**绕回起点**（回环让地图闭合更准）
   - ≤0.15 m/s；**不要横移**（麦轮横移时里程计不可信）；避开玻璃/镜面/纯黑物体
   - 随时看手机地图：灰色是未扫到区域，目标区域都走成白/黑才算建全
3. 回起点停车 → 点右上角「保存地图」

保存四件套（时间戳命名，不覆盖）：`~/RobotCode/04_map/map_<时间戳>.{pgm,yaml,posegraph,data}`
终端等价：`savemap`；电脑看图直接开 `.pgm`，实时看用 `mapv`（触摸屏本机）
或 `mapweb`（SSH 里没有图形会话时，浏览器看 —— 见 §5.1）。

## 5. Nav2 自主导航（日常）

1. `robotnav --nav2 [--vision]`（车放在建图起点附近，定位才准）
2. 手机「遥控」屏**地图上点一下** → Nav2 规划并开过去（可连续改道）
3. 途中自动绕障（动态纸箱等由全局+局部代价图处理）；窄道徘徊时看《12》P20 调参

调优记录与参数口径见《12_导航精度调优记录》（P13~P20）。

### 5.1 看地图 / 看膨胀层（三种方式，按终端选）

| 场景 | 命令 | 说明 |
|---|---|---|
| **小车触摸屏本机终端** | `mapv --costmap` | 直接开窗口，`q` 退出（要求本机有图形会话） |
| **SSH 进来（无图形会话）** | **`mapweb`** | 小车渲染成网页，PC/手机浏览器打开 `http://<小车IP>:8090/`，约 1.5 s 刷新 |
| **只想截一张图发人** | `mapv --costmap --save /tmp/x.png -r 5` | 存 PNG 后退出，再 `scp` 拉回电脑 |

> ⚠️ **SSH 里跑 `mapv` 会报 `Can't initialize GTK backend`** —— 小车上当前没有图形会话
> （Xorg/XWayland 都没起，`DISPLAY` 为空），不是脚本的问题，这时用 `mapweb`。

**`mapweb` 用法**

```bash
mapweb              # 启动：8090 端口 ｜ 视野 8 m ｜ 1.5 s 刷新
mapweb -r 4         # 视野 4 米（看箱子 / 窄缝细节）
mapweb -p 8091      # 换端口（8080 已被四屏 UI 占用）
mapweb -i 1.0       # 刷新间隔 1 秒
mapweb --status     # 是否在跑 + 图像更新时间 + 本机 HTTP 码
mapweb --stop       # 停止
```

启动后会自己打印地址（自动取本机 IP）。它是 `setsid` 脱离终端的，**SSH 断开也不停**，
要停必须显式 `mapweb --stop`。日志在 `/tmp/cm/render.log`、`/tmp/cm/http.log`。

**颜色怎么读**（nav2 代价 0~100）

| 颜色 | 代价 | 含义 |
|---|---|---|
| 浅黄 | 1~49 | 轻膨胀，好路 |
| 橙 | 50~99 | 重膨胀，能走但贵 |
| **红** | **100** | **车中心到不了** = 障碍本体 + 0.10 m 内切环 |
| 灰 | −1 | 地图外（未知区） |

> **判断"这条缝过不过得去"：别看红色多少，看红色之间有没有一条连续的浅色通道。**
> 一个 5 cm 的椅子腿会画成约 25 cm 的红团 —— 因为膨胀是按**车中心**算的，
> 这是正确表达，不是 bug。

### 5.2 地图编辑与自主探索（P2，手机网页新屏）

四屏变成**六屏**：遥控 / 航点 / 巡逻 / **探索** / **编辑** / 功能。

#### 编辑屏（`/edit.html`）——擦假障碍、画虚拟墙

1. 手机开 `http://<小车IP>:8080/edit.html`
2. 点 **「抓取当前地图」** 载入底图
3. 选画笔：**擦除假障碍**（青）/ **画虚拟墙**（红）；笔刷 1/3/5；✋ 可切平移
4. 在地图上拖动涂抹（松手才落盘，可撤销）
5. 点 **「另存新版本」** → 写 `robot_map_clean.pgm/yaml`

> ⚠️ **另存不覆盖原图**：`/edit/save` 指向 `robot_map` 会被服务端直接拒绝。
> ⚠️ **虚拟墙是软约束**：只让规划器绕行；车被手动遥控挤进去时，雷达/`collision_monitor` 照常工作、不硬拦。
> ⚠️ 想让 nav2 真的绕开，编辑层必须存在（`robot_map_clean.*`），`map_overlay.py` 会把它叠到 `/map` 上发成 `/map_edited`。

#### 探索屏（`/explore.html`）——前沿探索建图

1. **建图模式**起车：`robot --mode mapping --nav2`（探索要 nav2 规划）
2. 手机开 `/explore.html`，选模式：
   - **续建已有图**（默认）：载入 `robot_map.posegraph`，在原图上扩图
   - **从零探索**：不载入，建全新图
3. 点 **「开始探索」** → 车自动沿前沿走，走到没前沿为止
4. 点 **「存档」**（或探索自动结束时）→ 另存 `robot_map_v2`（已存在则 `_v3`）
5. 人工看图确认没问题后，点 **「启用为当前地图」**（二次确认，原图自动备份到 `04_map/bak_activate/`）

> ⚠️ **续建的前提**：车必须在**已有图覆盖范围内**，否则 slam_toolbox 匹配失败会生成
> **连通孤岛**（旧图断开、定位崩溃）。脚本会用 TF 校验，越界直接拒绝启动。
> ⚠️ **存档不切**：探索结果一律另存，**不自动激活** —— 探索出来的图可能有重影，
> 必须人工检查后再切。
> ⚠️ 续建只在 **mapping 模式**可用；localization 已加载 map，按钮会被拒。

#### 动态避障验收（B2）

```bash
# 终端 1：跑导航（建议带录包）
robotnav --nav2 --ekf --bag

# 终端 2：取证（人从车前走过去）
python3 ~/RobotCode/01_Project/03_SLAM/obstacle_check.py --csv /tmp/ob.csv
```

跑完看摘要里的「减速次数 / 急停次数 / 最长急停时长」，配合 `ros2 bag play` 复盘。
**判据**：行人横穿时绕行或减速等待、不撞上；贴脸障碍急停后停住、解除后能继续。

### 5.3 语音与远程入口（P3）

**语音屏（`/voice.html`）**：按住麦克风说话 → 识别 → 自动执行并播报结果。
词表（有限集合，词表外拒绝不动作）：**停止 / 前进 / 后退 / 左转 / 右转 / 回原点 /
「去&lt;地点名&gt;」/ 开始巡逻 / 停止巡逻**。
- 「去充电位」「去3D打印机」= 先查 `04_map/robot_map.places.json`，有这个名字才走（换图/没这个名字会拒绝并播报）
- 手动类限速 0.10 m/s、1.5 s 自动归零；**误识别随时按全宽红色「停 止」**（最高优先，直通本地停止链）
- ⚠ 浏览器麦克风需要安全上下文：`http://IP` 访问时 Chrome 不给权限。两种解法：
  ① `chrome://flags` → *Insecure origins treated as secure* 填 `http://<小车IP>:8080`；
  ② 或启动时用自签证书走 https。iOS Safari 部分支持，页面会给降级提示。

**ESP32 串口语音（本地链路，断网可用）**：
```bash
# 启动时带上串口设备（禁用 /dev/ttyACM0 —— 底盘占用）
robot --serial /dev/ttyUSB0
```
协议：115200 8N1，一行一 JSON（NDJSON），例：
`{"intent":"goto_place","args":{"name":"充电位"},"req_id":"esp32-1"}`；
串口回 ACK 行 `{"ack":"esp32-1","ok":true,"msg":"..."}` 供 ESP32 播报。
`{"intent":"stop"}` 免 req_id、最高优先。协议全文见
`01_Project/05_robot_ui/serial_cmd.py` 文件头。

**MQTT 远程（云端监控 + 下发目标，不暴露板端 HTTP）**：
```bash
# 云端 Broker 已配好（EMQX）；密码在 ~/.mqtt_pass（0600），勿写进命令行/文档
# ⚠ 当前云端 TLS 监听(8883)未修好，暂用 --no-tls 明文；修好后去掉 --no-tls 加 --tls-ca
robot --nav2 --mqtt --mqtt-args "--host 42.192.211.136 --port 1883 --no-tls --user robot_car --pass-file ~/.mqtt_pass"
```
- 上行 `robot/car01/telemetry`（状态/电量/位姿，含 dev/ts/seq）、`.../result`（执行回执）
- 下行 `robot/car01/task`（action: stop/goal/intent/manual/heartbeat，带 req_id 幂等）
- 在线状态 `robot/car01/presence`（online|offline，遗嘱自动发）
- **心跳租约**：远程手动命令 600 ms 心跳续租，断链/超时只停远程自己的命令；
  本地语音、已下发的自主任务、以及红色「停 止」都不受云端断网影响
- 无云端凭证时可本地试：`mosquitto` 起本地 broker + `--mqtt-args "--host 127.0.0.1 --port 1883 --no-tls"`（仅调试）

## 6. 视觉检测（YOLO11 · NPU）

- 模型：`yolo11.rknn`（COCO 80 类），三核 NPU 并行 37.5ms/帧
- 数据链：`/image_raw`(30fps) → `/detections`(30fps，`[cls,conf,x1,y1,x2,y2]×N`)
  → `/image_det`(10fps 画框 JPEG) → 手机 `/cam.mjpg`
- 手动单跑（调试用）：
  ```bash
  sr   # 先 source
  ros2 run cam_pub cam_pub              # 相机
  ros2 run rknn_infer rknn_infer       # 推理（-p conf_threshold:=0.25 可调）
  cd ~/RobotCode/01_Project/03_SLAM && python3 -m robot_ui.app   # 四屏 UI
  ```
- 权限：NPU/相机设备由 `/etc/udev/rules.d/99-dev-cam-npu.rules` 放行（已固化，重装系统需重放）

## 7. 常用命令速查

| 命令 | 作用 |
|---|---|
| `robot` / `robotnav` / `robotstop` / `robotcheck` | 建图 / 定位导航 / 急停全收 / 只预检查 |
| `robotnav --nav2` | 导航 + 六屏 UI（不开相机、不识别，最省） |
| `robotnav --nav2 --cam` | 导航 + 六屏 UI + 相机原始画面（不识别） |
| `robotnav --nav2 --vision` | 导航 + 视觉（YOLO11 检测）+ 四屏 UI 一条龙 |
| **`robotnav --nav2 --ekf`** | **日常导航推荐组合**：六屏 UI + EKF 融合（轮速+IMU），定位比纯轮速稳；`--ekf` 说明见 §2 |
| `drive ...` | 自动行驶建图（`spin` / `square` / `grid` / `home` / 自定义路线） |
| `mapv` / `scanview` | 实时地图 / 雷达点云（OpenCV 窗口） |
| `mapv --costmap` | 地图 + **nav2 膨胀层**：黄=轻膨胀、橙=重膨胀、**红=致命（车中心到不了）**。红区连成片 = 这条缝过不去，比量尺子直观 |
| `mapweb` | **SSH 无显示器时看地图**（`mapv` 在 SSH 里会因 GTK 失败）：小车渲染成网页 → 浏览器开 `http://<小车IP>:8090/`。`mapweb -r 4` 视野 ｜ `--status` ｜ `--stop`。**详见 §5.1** |
| `savemap` | 保存地图四件套（时间戳） |
| `odomhz` / `scanhz` | 底盘里程计 / 雷达频率（判断"活着没"最快） |
| `ros2 topic hz /detections` | 视觉检测频率（正常 ≈30） |
| `tfc` | TF 树图（应见 `map→odom→base_link→base_laser`） |
| `myip` / `whocar` / `wholidar` | 查 IP / 底盘串口占用 / 雷达串口占用 |
| `car` / `lidar` / `slam` | 手动分终端启动（不用一键脚本时） |
| `mapbackup` / `backup` | 地图打包 / 代码文档备份（见《11》） |

> 新终端第一次使用先 `sr`（source ROS 环境）；以上都是 `~/.bash_aliases` 里的别名。

## 8. 出问题怎么办

| 现象 | 先查 | 处理 |
|---|---|---|
| 手机打不开页面 | 同一 WiFi？地址带 `?k=` 了吗 | `cat /tmp/robot_ui.log` 找完整地址；`robotcheck` 看进程 |
| 页面是旧版单页 | —— | 旧 `phone_teleop.py` **已于 2026-10-20 归档**（`01_Project/bak_phone_teleop_20261020/`），现在任何启动方式都用 `robot_ui.app`（六屏）。看到旧界面说明是**改造前启动的残留进程**：`robotstop` 后重新启动即可 |
| 「开始巡逻」提示被 NAV 占用 | —— | NAV 5 分钟自动让出；或点遥控屏「清空」立即释放；新版已支持巡逻直接接管 |
| 检测画面黑/没有 | `pgrep -f rknn_infer`；`ros2 topic hz /image_det` | 相机/检测没起 → 重跑 `robotnav --nav2 --cam`（只要原始画面）或 `--vision`（要检测） |
| 检测报 `failed to open rknpu` | `ls -l /dev/dri/card*` 权限 | udev 规则丢失 → 重放 `99-dev-cam-npu.rules`（《14》） |
| 车不动（遥控/导航都） | `odomhz`；`ros2 topic info /cmd_vel` | 串口被占（`whocar`）→ `robotstop` 重来 |
| 地图点目标车不走 | `ros2 topic echo /goal_pose` 有没有发出去 | Nav2 没起（要 `--nav2`）；或定位漂移（车没放回建图起点附近） |
| `no valid path found` 循环 | 车是否停在致命格 | 手动挪车 / 《12》P16 的 costmap 参数 |
| 雷达没数据 | `scanhz`；`wholidar` | USB 重插；确认没有别的程序抢串口 |
| 摇杆松手车还在走 | —— | 立即点「停止」或终端 `robotstop` |
| 整个乱了 | —— | `robotstop` → 等 2 秒 → 重新 `robotnav --nav2 --vision` |

## 9. 安全与注意事项

1. **Nav2 有代价图避障，但仍非绝对安全**：动态低矮障碍（低于雷达平面）雷达看不见、
   视觉只检测不刹车——清场、留人看护，手边能按「停止」或断总电
2. 速度上限 0.20 m/s；**不要横移**；贴墙太近有雷达盲区
3. 不要同时开两套（预检查会拦截）；**旧 `phone` 别名与四屏 UI 抢 8080**，日常用四屏 UI
4. 四屏 UI 有 token 鉴权（`?k=`），但仍只在小车自己的局域网里用
5. 长时间跑注意电量与散热（SLAM + NPU 同时吃）；屏幕可拔掉省电
6. 地图是重要产物：定期 `tar czf ~/maps_$(date +%m%d).tar.gz -C ~/RobotCode 04_map`
   （`.gitignore` 已排除 `04_map/`，git 备份不含地图）
