小车操作速查卡

RK3588 + LD14P + 麦轮底盘 ｜ 详细说明：02_doc/09_使用说明.md ｜ 2026-09-20

① 启动 / 停止（约 10 秒）

robot　一键启动（底盘 / 雷达 / SLAM / 遥控）

robotstop　停止全套（或启动终端 Ctrl-C）

robotcheck　只检查设备与是否已有实例

启动后打印手机地址：http://<小车IP>:8080/（myip 查 IP）

② 手机遥控（零 App）

  • 手机连同一个 WiFi → 打开上面的地址
  • 摇杆：上=前进、左右=转向，松手即停；旁边的滑条调速度上限
  • 右上角按钮 「保存地图」（会先自动停车再存）
  • 地图：白=空闲　黑=障碍　灰=未扫到；红色三角=车

③ 建图要点

  • 先原地转一圈：drive spin（或摇杆只推左右）
  • 速度 ≤0.15 m/s；不要横移（麦轮里程计不可信）
  • 沿墙慢走、绕回起点（回环）；避开玻璃 / 镜面 / 纯黑物
  • 自动走：drive square -d 1.5 ｜ drive grid -L 2 -W 0.8 -n 3

④ 保存地图

手机点 「保存地图」，或终端 savemap → 存到

~/RobotCode/04_map/map_<时间戳>.*

.pgm 看图 ｜ .yaml 导航 ｜ .posegraph/.data 续建

时间戳命名 → 每次存档都保留，不覆盖

⑤ 常用命令

mapv 地图 ｜ scanview 点云 ｜ tfc TF 树

odomhz / scanhz 频率 ｜ whocar / wholidar 串口

drive -h 自动行驶全部预设与参数

⑥ 排错三行

  • 车不动 → odomhz 没数据？whocar 有占用？→ 重启底盘节点
  • 地图不更新 → SLAM 在跑吗？ros2 topic hz /map（应 ≈1.0 Hz）
  • 整个乱了 → robotstop → 等 2 秒 → robot

⑦ 安全

  • 没有避障！清空场地 + 留人看护 + 手边能按「停 止」
  • 速度 ≤0.2 m/s；贴墙太近有盲区
  • 网页只在本机局域网、无鉴权 → 用完 Ctrl-C 关掉
