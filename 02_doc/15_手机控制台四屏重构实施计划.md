```python
MIME = {'.html': 'text/html; charset=utf-8', '.css': 'text/css; charset=utf-8',
        '.js': 'application/javascript; charset=utf-8', '.svg': 'image/svg+xml',
        '.png': 'image/png', '.jpg': 'image/jpeg', '.ico': 'image/x-icon',
        '.json': 'application/json; charset=utf-8'}

    def serve_static(self, path):
        """/ → index.html；其余按 www/ 下相对路径读盘。禁止 .. 越权"""
        name = 'index.html' if path in ('/', '') else path.lstrip('/')
        fp = os.path.normpath(os.path.join(WWW_DIR, name))
        if not fp.startswith(WWW_DIR) or not os.path.isfile(fp):
            return self._send(404, 'text/plain; charset=utf-8', 'not found'.encode())
        ext = os.path.splitext(fp)[1].lower()
        with open(fp, 'rb') as f:
            self._send(200, MIME.get(ext, 'application/octet-stream'), f.read())
```

    def serve_events(self):
        """GET /events：SSE 单向推送 state，0.5s 一拍"""
        self.send_response(200)
        self.send_header('Content-Type', 'text/event-stream')
        self.send_header('Cache-Control', 'no-store')
        self.end_headers()
        try:
            while True:
                data = json.dumps(self.node.state(), ensure_ascii=False).encode('utf-8')
                self.wfile.write(b'data: ' + data + b'\n\n')
                time.sleep(0.5)
        except (BrokenPipeError, ConnectionResetError):
            pass

**Step 1:** 核心类（先满足"抢控制权"这一件事，不做过设计）：

```python
# state_store.py
import time

class ModeMgr:
    """控制权互斥：同一时刻只有一种来源能动 /cmd_vel 或发目标。

    IDLE / TELEOP(摇杆) / NAV(点选目标·多点) / PATROL(巡逻)
    规则：空闲随便认领；被占用时除非 force=True（网页端需二次确认），否则拒绝。
    超时自动释放（TELEOP 3s 无指令、NAV/PATROL 由任务结束显式 release）。
    """
    TIMEOUT = {'TELEOP': 3.0, 'NAV': None, 'PATROL': None}

    def __init__(self):
        self.lock = __import__('threading').Lock()
        self.mode, self.holder, self.t0 = 'IDLE', None, 0.0

    def claim(self, who, mode, force=False):
        with self.lock:
            self._expire()
            if self.mode not in ('IDLE', mode) and not force:
                return False, '%s 被 %s 占用' % (self.mode, self.holder)
            self.mode, self.holder, self.t0 = mode, who, time.time()
            return True, 'ok'

    def release(self, who):
        with self.lock:
            if self.holder == who:
                self.mode, self.holder = 'IDLE', None
            return self.mode

    def _expire(self):
        t = self.TIMEOUT.get(self.mode)
        if t and time.time() - self.t0 > t:
            self.mode, self.holder = 'IDLE', None

    def snapshot(self):
        with self.lock:
            self._expire()
            return {'mode': self.mode, 'holder': self.holder}
```

**接口（对应屏3 UI 字段）：**

```

GET /patrol/go                  # 开始巡逻（可选 ?loop=1）
GET /patrol/pause | resume | skip | cancel
```

**PatrolRunner 要点：**
- 线程内逐点发 `NavigateToPose` action（ActionClient，nav2 标准接口），到点后 `time.sleep(dwell_s)`；
- 状态字典 `{'cur': 2, 'total': 4, 'per': ['done','done','active','pending'], 'elapsed': 42, 'eta': 16, 'loop': True}`，`state()` 聚合进 `/events` 推给屏3；
- `skip` = cancel 当前 goal 后立即下发下一个；`cancel` = 停车 + release('PATROL')；
- 失败点标记 `failed` 并继续下一点（对应引文"失败跳过"）；
- 逐点剩余时间估算：路径长 ÷ 0.15 m/s（与实机速度上限一致）。
- **预检复用**：每个点入队时仍走 `GoalPrecheck`（与现有 wp_add 同一份）。

**决策点（动工前必须确认）：** 逐点停留 → 必须**顺序 NavigateToPose**；`FollowWaypoints`（现有 P34 代码）**保留**给"连发不停留"场景，两个入口并存：`/wp/*`（旧行为不动）与 `/patrol/*`（新）。

**冒烟（板端，nav2 栈已起）：** `curl /patrol/points` → 配 2 点；`curl '/patrol/go?loop=1'` → 车逐点走、每点停 3s；`curl /patrol/skip` 立即切点；`curl /patrol/cancel` 就地停车。
