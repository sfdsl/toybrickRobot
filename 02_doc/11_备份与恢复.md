## 2. 首次配置（已完成；换机时照做）

```bash
# ① SSH 密钥（本机已有 ~/.ssh/id_ed25519，注释 toybrick）
ssh-keygen -t ed25519 -C "toybrick"        # 已有就跳过
cat ~/.ssh/id_ed25519.pub                  # 复制整行 → GitHub → Settings → SSH and GPG keys → New SSH key

# ② 写入 GitHub 的 host key（免得首次连接弹确认；指纹与 GitHub 官方文档一致）
ssh-keyscan -t rsa,ecdsa,ed25519 github.com >> ~/.ssh/known_hosts

# ③ 验证（应输出 Hi <用户名>! You've successfully authenticated）
ssh -T git@github.com

# ④ 关联远端并首次推送（注意：github.com 后面是【冒号】，不是斜杠！）
cd ~/RobotCode
git remote add origin git@github.com:<用户名>/<仓库名>.git
git push -u origin main
```

**踩过的坑**：把地址写成 `git@github.com/用户名/仓库.git`（斜杠）会报
`does not appear to be a git repository` —— git 会把它当**本地路径**去找；SSH 地址必须用**冒号**。

## 3. 日常备份（两条命令）

```bash
source ~/.bash_aliases     # 新终端或改过别名后先执行一次
backup        # 代码+文档：git add -A → commit（提交信息带日期时间）→ push
backuplog     # 看当前改动 + 最近 5 条提交（确认备份内容）
mapbackup     # 地图：打包成 ~/maps_<日期_时分>.tar.gz（随后拷 U 盘/电脑）
```

别名定义（在 `~/.bash_aliases` 里）：

```bash
alias backup='cd ~/RobotCode && git add -A && git commit -m "备份 $(date "+%F %H:%M")" && git push'
alias backuplog='cd ~/RobotCode && git status -sb && git log --oneline -5'
alias mapbackup='tar czf ~/maps_$(date +%m%d_%H%M).tar.gz -C ~/RobotCode 04_map && ls -lh ~/maps_*.tar.gz | tail -1'
```

> 建议节奏：**改完代码/文档 → `backup`**；**每次建图存图后 → `mapbackup`**（或定期把 `04_map/` 同步到电脑）。

## 5. 换机器 / 重装后的恢复

```bash
# ① 取回代码与文档
git clone git@github.com:sfdsl/toybrickRobot.git ~/RobotCode
cd ~/RobotCode && git remote -v

# ② 还原 slam_toolbox 上游代码 + 我们的适配补丁
cd ros2_ws/src
git clone -b foxy-devel https://github.com/SteveMacenski/slam_toolbox.git
git -C slam_toolbox apply ../../patches/slam_toolbox_local_changes.patch
#   补丁若因上游更新打不上：直接用 patches/slam_toolbox_files/ 里的 4 个改后文件覆盖

# ③ 编译
cd ~/RobotCode/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select slam_toolbox base_driver ldlidar robot_bringup
source install/setup.bash

# ④ 地图（如果之前 mapbackup 过）
tar xzf ~/maps_<日期>.tar.gz -C ~/RobotCode          # 还原 04_map/

# ⑤ 设备与权限（换机必查）
ls -l /dev/CAR_BASE /dev/LD14P                       # 串口别名（udev 规则见《01》P0-2）
groups | grep -q dialout && echo 'dialout ✓'
```

> 补丁内容：`CMakeLists.txt`、`config/mapper_params_online_async.yaml`、
> `launch/online_async_launch.py`、`launch/online_sync_launch.py`（去 nav2_common 依赖、
> `use_sim_time=false`、`base_frame=base_link`、`map_update_interval=1.0` 等本机适配）。

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `does not appear to be a git repository` | remote 地址用了斜杠 → 改成 `git@github.com:用户名/仓库.git`（**冒号**） |
| `Permission denied (publickey)` | 公钥没加到 GitHub（或加到了别的账号）→ 先 `ssh -T git@github.com` 看提示 |
| push 时提示输入 passphrase | 建密钥时设了口令，输一次即可；想免输入：`ssh-add ~/.ssh/id_ed25519` |
| `Updates were rejected` | 远端有本地没有的提交（如在网页上改过文件）→ `git pull --rebase` 后再 `backup` |
| 怀疑仓库变大 | 看 `git ls-files` 输出里有没有 `04_map/`；确认 `.gitignore` 生效后再 `backup` |
| 想彻底移除已提交的大文件 | 需重写历史：`git update-ref -d HEAD` + 重新提交 + `git gc --prune=now`（本仓库 2026-09-21 就是这么把地图摘掉的） |
| 提交身份是 `toybrick <toybrick@debian>` | 想让 GitHub 显示你的账号：`git config user.name/user.email` 后 `git commit --amend --reset-author` |
